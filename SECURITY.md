# Security policy

## Supported versions

Security fixes are applied to the latest released version of `hermes-rheo`.

## Reporting a vulnerability

Please report vulnerabilities privately through
[GitHub security advisories](https://github.com/3mcloud/hermes-rheo/security/advisories/new)
rather than a public issue. Include the affected version, a description of the
problem and, if possible, a minimal input file that reproduces it. You can
expect an acknowledgement within a week.
